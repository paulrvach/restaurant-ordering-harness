# Shared image direction

Read `social/brand/GUIDELINES.md` before generating. Visual reference: https://motionimo.xyz/video/a-day-in-hr — A Day in HR, by MO MO / MO Creative Studio; original: https://vimeo.com/1204518661.

Use case: social campaign visual for a restaurant ordering harness.

Direction: a recognizable restaurant workday expressed through mixed-media photography, precise enlarged software UI and playful cutout collage. Use a believable close-up work scene or a clean light collage field. Give the task one clear visual focus. Pair organic photographic texture with crisp digital layers, clean sans-serif type, strong changes of scale and generous negative space.

Palette: white #FFFFFF, work green #1E7246 and mint #C6F1D8 lead; restrained gray #919794, sage #5E7267 and slate #3F4B62 support. Use near-black #101713 for legible text. Choose one main accent, rather than making every object green.

Composition: choose one — workday photo with one oversized UI overlay; a green/mint operational table close-up; or 3–6 relevant cutout objects surrounding one short central headline. Adapt to recipes, ingredients, vendor packs, inventory and order drafts. UI layers must explain the task. A small time label, message bubble or cursor can add personality when meaningful.

Typography: original short headline in clean sans-serif lettering. Keep essential text readable at feed size. When prices, quantities or labels must be exact, generate the base visual and add the text in a deterministic layout pass.

Avoid: rustic cookbook styling, decorative serif headlines, a beige product still life without work/UI context, neon AI clichés, unreadable dashboards, fake metrics, copied logos or lifted reference assets. Use our own content. Clearly distinguish concept imagery from a real product screenshot.
