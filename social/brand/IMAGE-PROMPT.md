# Shared image direction

Read social/brand/GUIDELINES.md and use social/brand/approved-poster.png as the visual reference.

Create an original restaurant-ordering announcement or progress image with a tomato-red and warm-cream palette, black ink, and an occasional muted olive accent. Use large, irregular, fluid Kanos-style uppercase display lettering and small, clean sans-serif utility text.

Use creative hand-drawn restaurant-work characters or operational objects, imperfect ink contours, cream fills and restrained halftone. Add only a few tasteful organic marks or decals. Apply a coherent fine uncoated-paper texture and subtle ink wear across the entire image, visually like a paper layer set to Overlay at moderate opacity. Keep typography and important content readable.

Use the supplied references for inspiration; create original artwork. Generated typography approximates Kanos. The approved reference PNG is flattened, not an editable layered file.

Use the post's supplied copy and supported claims. Recipes lead to priced vendor order drafts for human review. Do not invent metrics. Label generated artwork accurately. Save the final prompt, generation method and descriptive alt text with each post.
